# Predprof-Wibecoding

## План работы команды

### 1: Основа
- **backend/core** - сервер + база данных + модели
- **backend/auth** - регистрация и вход пользователей
- **frontend/core** - базовый интерфейс
- **frontend/auth** - формы входа/регистрации

### : Задачи
- **backend/tasks** - добавление/решение задач + автопроверка
- **frontend/tasks** - каталог задач + интерфейс решения

### 3: PvP
- **backend/pvp** - соревнования + рейтинг
- **frontend/pvp** - интерфейс

### 4: Финал
- **analytics** - статистика пользователей + графики прогресса
- **admin** - админ-панель (управление всем)
- **deployment** - запуск на сервере
